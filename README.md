# Hybrid Movie Recommendation System

An AI-powered Hybrid Movie Recommendation System built using Python, TensorFlow, Flask, and Machine Learning techniques.

This project combines:
- Content-Based Filtering
- Deep Learning Recommendation System
- TensorFlow Recommenders
- Flask Web Application

to recommend movies based on user preferences and movie similarity.

---

## Features

- Hybrid Recommendation System
- Content-Based Movie Recommendation
- Deep Learning Recommendations
- TensorFlow Recommenders Integration
- Movie Rating Prediction
- Movie Poster Fetching using API
- Flask Web Interface
- Personalized Recommendations

## API Used

---

## Project Workflow

1. Load MovieLens Dataset
2. Merge Ratings and Movies Data
3. Create Content-Based Recommendation System
4. Train Deep Learning Recommendation Model
5. Generate Personalized Recommendations
6. Predict Movie Ratings
7. Display Recommendations using Flask Web App
